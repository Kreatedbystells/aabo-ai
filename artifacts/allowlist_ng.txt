# Nigerian domain reputation list — the gap that global popularity lists leave.
#
# No Nigerian domain appears in the top 100,000 of the merged global popularity list:
# jumia.com.ng is ranked 212,517, gtbank.com 365,782, paystack.com 432,967,
# firstbanknigeria.com 505,608 and zenithbank.com 527,015. A reputation layer built only
# from global traffic data therefore gives a Nigerian user no protection on the sites they
# use most, which is exactly what the hard-case test showed.
#
# Entries are well-known Nigerian banks, payment providers, telecommunication operators,
# retailers, media houses, utilities and institutions. Being on this list is NOT a claim
# that a domain is safe; it means that when the classifier accuses it, the accusation is
# more likely to be a false positive and should be shown to the user as unverified rather
# than malicious. Domain identity is never a feature of the classifier, so this list
# affects presentation only and cannot change the model's verdict.
