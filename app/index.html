What this is

Aabo AI classifies a web address from sixteen features of the URL string — its length, its depth, its path, its tokens — computed from the string alone, with no request to the address itself.

No page behind the link is ever fetched, here or by the service that scores it, and the address is sent to no third party. Scoring happens on this site's own server — the model does not run in your browser — and each scan is written to the log below. On the hosted copy that log sits on the instance serving you and is cleared when it restarts, so it is not a durable record.

The site also carries a bundled blocklist of 112,433 domains reported as hostile. It can only support an accusation the classifier has already made: it never creates one, and it never clears one. Where a trusted list and that list disagree about the same domain, the verdict is shown as unverified and the disagreement is named.

How far to trust it

Deployed model rf-v2, a Random Forest over 235,370 labelled URLs. In-dataset accuracy 95.7%; accuracy on unseen addresses from independent sources 88.4%, rising to 95.5% (best case) once known domains are accounted for — an upper bound that resolves every conflict in favour of the legitimate label, on a test set in which most legitimate addresses are bare domain names from the same collection.

Legitimate URLs that carry a path are still accused 41.6% of the time. A verdict is decision support, never a guarantee.

Never definitive

A link judged legitimate can still be malicious if the page behind it is compromised after it was written. Check the address bar, not only this answer.
